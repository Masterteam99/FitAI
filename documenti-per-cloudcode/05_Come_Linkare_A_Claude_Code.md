# COME LINKARE I DOCUMENTI A CLAUDE CODE
## (Senza Google Drive)

---

## ✅ OPZIONE 1: COPIA-INCOLLA DIRETTO (MIGLIORE)

Questo è il metodo **più semplice e affidabile**.

### Step:

1. **Scarica il file dal browser**
   - Vedi i file come "allegati" in questa chat
   - Click download su `CLAUDE_CODE_MASTER_PROMPT.md`
   - Salva nel computer

2. **Apri il file con un editor di testo**
   - Blocco Note, VS Code, Sublime, ecc.

3. **Seleziona TUTTO il testo**
   - Ctrl+A (Windows/Linux)
   - Cmd+A (Mac)

4. **Copia**
   - Ctrl+C (Windows/Linux)
   - Cmd+C (Mac)

5. **Vai su Claude Code**
   - https://claude.com/claude-code
   - Incolla nel chat input
   - Ctrl+V o Cmd+V

6. **Premi INVIO**

---

## ✅ OPZIONE 2: GitHub (Se hai GitHub Account)

Più complesso ma utile se vuoi versioning.

### Step:

1. **Crea nuovo repository privato su GitHub**
   - https://github.com/new
   - Nome: "motion-insight-tasks" (o simile)

2. **Crea file nel repo**
   - Click "Add file" → "Create new file"
   - Nomina: `CLAUDE_CODE_MASTER_PROMPT.md`
   - Copia-incolla il contenuto
   - Commit

3. **Prendi il link RAW**
   - Apri il file su GitHub
   - Click "Raw" button (top-right del file)
   - Copia l'URL da browser

4. **Passa a Claude Code**
   ```
   Ho caricato i task qui:
   https://github.com/[TUO_UTENTE]/motion-insight-tasks/raw/main/CLAUDE_CODE_MASTER_PROMPT.md
   
   Puoi leggerlo e implementare i task?
   ```

5. **Claude Code leggerà il file**
   - Avrà accesso al contenuto
   - Implementerà come richiesto

## ✅ OPZIONE 3: Dropbox/OneDrive Public Link

Se usi Dropbox o OneDrive con link pubblici.

### Step:

1. **Carica file su Dropbox**
   - Dropbox.com → Upload file
   - Right-click file → Share
   - Create link (deve essere PUBLIC)
   - Copia link

2. **Modifica link per renderlo "raw"**
   - Dropbox: cambia `?dl=0` in `?dl=1`
   - Esempio:
   ```
   DA: https://www.dropbox.com/s/abcd1234/file.md?dl=0
   A:  https://www.dropbox.com/s/abcd1234/file.md?dl=1
   ```

3. **Passa link a Claude Code**
   ```
   Ho caricato i task su Dropbox:
   [INCOLLA LINK QUI]
   
   Leggi il file e implementa come scritto.
   ```

## 🚫 SCONSIGLIATO: Google Drive

❌ Google Drive non permette link diretti al contenuto (per motivi di sicurezza)

Se vuoi comunque usare Google Drive:
- Carica file su Drive
- Right-click → "Share" → Link pubblico
- Copia link
- **MA:** Claude Code non può leggere direttamente da Drive
- Dovrai comunque copia-incollare il testo manualmente

**Consiglio:** Usa OPZIONE 1 (copia-incolla) - è più veloce!
